# Automação

Esta pasta contém os testes automatizados desenvolvidos com Cypress para o desafio técnico da Speedmilhas.

- `api-busca.cy.js`: testes de API relacionados à busca de passagens.
- `busca-passagens.cy.js`: testes E2E da interface de busca de passagens.

Para consultar os pré-requisitos e as instruções de execução, consulte o `QA_NOTES.md` na raiz do repositório.
